#   Il tuo cloud privato: sincronizzazione decentralizzata con Syncthing Lite

Hai mai desiderato avere i tuoi file disponibili ovunque, ma senza affidarti a   servizi cloud centralizzati?  
**Syncthing Lite** è la chiave: un'app Android **leggera e open-source** che ti permette di accedere, sfogliare e scaricare file in modalità *on-demand* da qualsiasi dispositivo che utilizza Syncthing — senza dover sincronizzare tutto.

---

##  Cos'è Syncthing e perché è libertà digitale

- **Syncthing** è un software open-source peer-to-peer per la sincronizzazione di file tra dispositivi.  
- Funziona come un *cloud personale*: i tuoi dati restano sui tuoi hardware, criptati, senza passare da server di terze parti 0.

---

##  Cosa offre Syncthing Lite

- Accesso **on-demand** ai file su dispositivi remoti, senza scaricare intere cartelle localmente 1.  
- Ideale per **smartphone con poco spazio**: visualizzi anteprime e decidi cosa scaricare.  
- Progetto riattivato recentemente, ancora in sviluppo: backup consigliato prima dell’uso 2.

---

##  Come iniziare (guida rapida per Android)

1. Installa **Syncthing Lite** dal [F-Droid](https://f-droid.org/packages/com.github.catfriend1.syncthinglite/) o Google Play 3.  
2. All’avvio, segui il setup guidato per aggiungere un dispositivo: manualmente, via QR o scoperta in LAN 4.  
3. Sfoglia le cartelle condivise da altri dispositivi e scarica i file che ti servono. L’app ti mostrerà il progresso come "0 %" (atteso), perché non sincronizza tutto in background 5.  
4. Nota: all'uscita forzata, la riconnessione può richiedere alcuni minuti 6.

---

##  Vantaggi reali

- **Usi solo ciò che ti serve** → risparmi spazio e dati.  
- **Proteggi la tua privacy** → i tuoi file non viaggiano su server commerciali.  
- **Comandi tu la sincronizzazione**, non altri.  
- **Compatibile con Syncthing "classico"**, quindi puoi creare un ecosistema privato tra PC, NAS e smartphone.

---

##  Altri utili contesti di Syncthing

Per un cloud personale completo, puoi:
- Usare Syncthing desktop su Windows/Linux/macOS con interfaccia web 7.  
- Sincronizzare note, foto, cartelle private, e fare backup senza plugin o abbonamenti.  
- Combinare con strumenti come **Syncthing Fork** se vuoi più funzionalità su Android 8.

---

##  Conclusione

Usare **Syncthing Lite** è un passo concreto verso la tua **sovranità digitale**: niente cloud di mezzo, niente lock-in, solo file tuoi, sincronizzati come vuoi tu.  
È la tua nuvola privata, leggera, libera.
