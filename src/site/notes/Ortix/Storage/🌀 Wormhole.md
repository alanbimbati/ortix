## 🌀 Wormhole: il passaggio segreto dei file

In un’epoca dominata da **cloud permanenti**, account obbligatori e link che restano in vita più del necessario, **Wormhole** rappresenta un ritorno a un’idea semplice e potente:  
> *condividere un file solo con chi deve riceverlo, per il tempo strettamente necessario*.

Wormhole nasce come strumento **effimero**, **privacy-first** e **senza attriti**, pensato per invii **una tantum** di file o cartelle, senza lasciare tracce superflue.

---

## 🔐 Privacy by design (non per marketing)

A differenza di servizi come WeTransfer, Wormhole non è un “magazzino temporaneo nel cloud”, ma un **tunnel crittografato**.

Caratteristiche chiave:

- 🔒 **Crittografia end-to-end**: la chiave è nel link, non sul server  
- 🕳️ **Nessun account** richiesto  
- 🧠 **Zero conoscenza**: il server non può leggere i contenuti  
- ⏳ **Scadenza automatica**: il file sparisce dopo il download (o dopo un tempo limite)

Il paradigma è chiaro: **il file esiste solo mentre serve**.

---

## 📦 File e cartelle, senza compromessi

Wormhole consente di inviare:

- singoli file  
- **intere cartelle** (zippate automaticamente)  
- file di grandi dimensioni (molto oltre i limiti email)

Il tutto tramite un **semplice link**, condivisibile via chat, email o anche a voce.

---

## 🔁 Una volta sola (e basta)

Uno degli aspetti più interessanti — e spesso sottovalutati — è la **natura “one-shot”** del trasferimento.

- Il file può essere:
  - scaricato **una sola volta**
  - oppure rimanere disponibile per un tempo limitato
- Dopo:
  - ❌ link invalido  
  - ❌ contenuto distrutto  
  - ❌ nessuna replica residua

Questo approccio riduce drasticamente:
- superficie di attacco  
- esposizione accidentale  
- archiviazioni non intenzionali

È **l’opposto concettuale del cloud eterno**.

## 🧠 Una filosofia, prima che uno strumento

Wormhole incarna un principio più ampio, caro a chi riflette su **privacy, Bitcoin e decentralizzazione**:

> *non tutto deve essere archiviato, indicizzato e monetizzato*.

Alcuni dati devono **solo passare**, come un sussurro.  
Entrare in un wormhole, attraversarlo… e sparire.

## 🌱 Quando usarlo (e quando no)


**Ideale se:**
- devi inviare documenti sensibili  
- condividi backup temporanei  
- vuoi evitare cloud e account  
- ti serve qualcosa di immediato

**Non ideale se:**
- cerchi sincronizzazione continua  
- vuoi collaborazione a lungo termine  
- ti serve versioning storico
