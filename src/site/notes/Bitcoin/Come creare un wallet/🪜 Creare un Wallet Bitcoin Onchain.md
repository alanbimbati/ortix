# 🪙 Guida alla Creazione di un Wallet Bitcoin

### Percorsi di sovranità digitale, dal principiante all'esperto

Bitcoin è sicuro per design, ma la robustezza del tuo capitale dipende esclusivamente dalla qualità dell'**entropia** (casualità) usata per generare le tue chiavi private.

> [!QUOTE]
> 
> Bitcoin protegge le tue chiavi con la matematica, ma tu sei responsabile del modo in cui nascono.

---

## 📊 Comparazione dei Metodi di Generazione

| **Caratteristica**   | **🥉 Metodo 1: Facile**  | **🥈 Metodo 2: Medio**    | **🥇 Metodo 3: Difficile**      |
| -------------------- | ------------------------ | ------------------------- | ------------------------------- |
| **Strumento**        | Smartphone / App         | Software + Passphrase     | Dadi fisici                     |
| **Entropia**         | Generata dal dispositivo | Ibrida (Software + Umana) | Puramente Fisica (Manuale)      |
| **Difficoltà**       | Bassa (5 min)            | Media (20 min)            | Alta (1 ora+)                   |
| **Punto di Fiducia** | Software e Produttore    | Software e Memoria        | Te stesso (Capacità di calcolo) |
| **Protezione Furto** | Solo fisica (Seed)       | Fisica + Mentale          | Fisica (Massima Entropia)       |

## 🧭 Scegli il tuo livello di consapevolezza

### [[Bitcoin/Come creare un wallet/🥉 Metodo 1 — Crazione di un wallet Livello Facile\|🥉 Metodo 1 — Crazione di un wallet Livello Facile]]

Ideale per: Piccole somme, test o nuovi utenti.

Si affida agli algoritmi standard del sistema operativo e dell'app (es. BlueWallet) per generare le 12 parole.

### [[Bitcoin/Come creare un wallet/🥈 Metodo 2 — Crazione di un wallet Livello Medio\|🥈 Metodo 2 — Crazione di un wallet Livello Medio]]*

Ideale per: Chi vuole proteggere risparmi significativi.

Utilizza una Passphrase (25ª parola) per creare wallet nascosti e proteggersi dal furto fisico della seed phrase.

### [[Bitcoin/Come creare un wallet/🥇 Metodo 3 — Crazione di un wallet Livello Difficile\|🥇 Metodo 3 — Crazione di un wallet Livello Difficile]]

Ideale per: Massimalisti della sicurezza e grandi patrimoni.

Elimina ogni possibile "backdoor" informatica generando l'entropia manualmente tramite il lancio di dadi. Richiede la massima attenzione per evitare errori di calcolo.

---

*La passphrase si può sempre aggiungere a qualunque wallet, quindi anche ad un wallet creato con il Metodo 1 o il Metodo 3
