# 🔶 Passport: eleganza airgapped per Bitcoiner esigenti

✨ **Passport è l'hardware wallet che sembra uscito da un set di James Bond.**  
Design premium, completamente airgapped, Bitcoin-only. È Coldcard con stile.

---

## 🔐 Cos'è Passport?

Passport è un **[[Bitcoin/Wallet/Hardware Wallet\|hardware wallet]]** prodotto da **Foundation Devices**.

Versioni disponibili:
- **Passport Batch 2** (~270€) → versione attuale, design premium

🔶 È uno degli hardware wallet più **belli esteticamente**, senza sacrificare sicurezza.

---

## 📱 Caratteristiche

### ✅ Punti di Forza

- **Completamente airgapped** → solo QR code e microSD, zero cavi
- **Bitcoin-only** → nessuna distrazione, massima sicurezza
- **Completamente open source** → hardware, firmware, companion app
- **Design premium** → batteria ricaricabile, chassis in metallo
- **Display a colori** → grande, chiaro, facile da leggere
- **Fotocamera** → per scansionare QR code (PSBT, wallet import)
- **Batteria integrata** → ricaricabile, autonomia di settimane
- **Secure Element** → Microchip ATECC608B
- **PIN alfanumerico** → con tastierino fisico
- **Prodotto negli USA** → manifattura americana

### ⚠️ Limiti

- **Prezzo alto** → ~270€ (stesso range di Coldcard)
- **Community più piccola** → meno popolare di Coldcard/Ledger
- **Batteria** → va ricaricata (ma dura settimane)

---

## 🧠 Funzionalità

- Supporta [[Bitcoin/Wallet/✍️ PSBT\|✍️ PSBT]] via **QR code animati o microSD**
- Compatibile con **Envoy** (app mobile di Foundation), [[Bitcoin/Wallet/🐦 Sparrow Wallet\|🐦 Sparrow Wallet]], [[Bitcoin/Wallet/⚡ Electrum\|⚡ Electrum]]
- [[Bitcoin/Wallet/🔐 Multisig\|🔐 Multisig]] facile da configurare
- Backup seed su metallo consigliato ([[Bitcoin/Wallet/🪨 Steelwallet\|🪨 Steelwallet]])
- Supporto per **passphrase BIP39** (25a parola)
- Firmware verificabile e aggiornabile via microSD

🔶 **Envoy app** (mobile wallet companion) si integra perfettamente per un setup airgapped completo.

## ⚔️ Passport vs Coldcard

Entrambi sono **airgapped, Bitcoin-only, open source**.

**Coldcard:**
- Design più tecnico/industriale
- Più funzioni avanzate (duress PIN, brick me PIN)
- Display monocromatico piccolo
- Si alimenta via USB (niente batteria)
- Community più grande

**Passport:**
- Design elegante e moderno
- Batteria integrata (più portatile)
- Display a colori grande
- Fotocamera integrata (QR più facili)
- Mobile-first con Envoy app

🔶 **Passport = Coldcard per chi vuole anche estetica e comodità.**
