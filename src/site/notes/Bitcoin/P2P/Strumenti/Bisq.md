# 🤖 Bisq

**Bisq** è una piattaforma di scambio Bitcoin P2P completamente decentralizzata e resistente alla censura.

- **Sito Ufficiale**: [bisq.network](https://bisq.network)
- **Caratteristiche**: Software desktop e mobile, rete Tor, governance tramite DAO.
